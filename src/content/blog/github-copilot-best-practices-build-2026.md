I'm thrilled to announce that I'll be presenting **"GitHub Copilot Best Practices"** at Microsoft Build 2026 in Seattle!

## Session Overview

In this session, we'll go beyond the basics and explore how to truly integrate GitHub Copilot into your development workflow. Whether you're writing code, reviewing pull requests, or debugging tricky issues, Copilot can be your superpower — if you know how to use it effectively.

## What You'll Learn

- **Prompt engineering for code**: How to write clear, context-rich prompts that yield better suggestions
- **Workspace agents and custom instructions**: Tailoring Copilot to your project's conventions
- **Multi-file editing with Copilot Edits**: Orchestrating large refactors across your codebase
- **Code review with Copilot**: Using AI-assisted reviews to catch bugs before they ship
- **Security best practices**: Ensuring Copilot-generated code follows OWASP guidelines

## Key Takeaways

The biggest insight from my research preparing this talk: developers who write detailed `.github/copilot-instructions.md` files see significantly better suggestions. Context is everything.
